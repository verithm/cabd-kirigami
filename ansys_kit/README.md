# CABD 데이터 수집 키트

학습·시험용 형상 768개를 PC 3대에 나눠 자동으로 해석하는 키트입니다. 이 폴더에는 **이 PC가 맡은 형상(약 256개)**만 들어 있습니다.

## 무엇을 돌리나

- 형상 1개당 해석 2번
  - 살짝 젖음: 팀 공용 프로젝트의 `bi_370_13_3_12` (SYS 5)
  - 완전 젖음: `mo_13_13_3_12` (SYS 6)
- 재료, 접촉(bonded), 경계조건(뒷벽 바깥면 고정, 가운데 힌지 안쪽 모서리 +15 mm)은 원래 프로젝트와 같은 규칙으로 형상마다 자동으로 다시 지정합니다.
- 해석 설정은 벤치마크 키트와 같습니다(자동 시간 스텝, 초기 40 / 최소 20 / 최대 160 substep).
  - 수렴하지 않으면 힌지 메시를 더 굵게(0.2 mm, 4층) 바꿔 한 번 더 자동으로 해석합니다.
- 메시: 전체 0.6 mm입니다. 힌지 3개는 0.1 mm hex 요소(깊이 방향 8층)로 촘촘하게 나눕니다. 이 메시가 품질 검사를 통과하지 못하면 조금 더 굵은 설정으로 자동으로 바꿉니다.
- 솔버는 직접법(sparse)으로 고정합니다.
- 순서: 학습용 형상을 먼저 돌리고, 그다음 시험용 형상을 돌립니다.

## 준비물

- Ansys Student **2026 R1** (벤치마크 때와 같은 버전)
- 여유 디스크 약 5 GB. 해석 중에만 쓰고 형상마다 지웁니다. 남는 결과는 형상당 약 1 MB입니다.
- 시간: 형상 1개에 **약 10~20분**입니다. 힌지가 얇을수록 오래 걸리고, 키트를 만든 노트북에서 가장 얇은 힌지 형상이 약 15분이었습니다. 따라서 256개에 **약 2~4일**이 걸립니다(추정). 수렴하지 않아 다시 해석하는 형상은 더 오래 걸립니다.

## 실행 방법

1. zip을 풀고, 폴더를 **영문 경로**로 옮깁니다. 예: `C:\CABD_collect_PC1`
   - 경로에 한글이나 공백이 있으면 실행을 멈춥니다(벤치마크와 같음).
2. 실행 전 확인:
   - 노트북은 **반드시 전원 어댑터를 연결**합니다.
   - Ansys와 다른 무거운 프로그램은 모두 끕니다.
   - 스크립트가 실행되는 동안에는 절전 모드에 들어가지 않습니다. 다만 **노트북 덮개를 닫으면 잠들 수 있으니** 덮개는 열어 둡니다.
3. `run_collect.bat`을 더블클릭합니다.
   - 검은 창에 형상마다 진행 상황과 남은 시간 추정이 찍힙니다.
   - 끝나면 폴더에 `collect_result_PC<번호>_<PC이름>_<날짜>.zip`이 생깁니다. 이 파일을 단톡방에 올려 주세요.

## 중간에 멈춰도 됩니다

- 창을 닫거나 PC를 재부팅해도 됩니다. `run_collect.bat`을 다시 실행하면 **끝난 형상은 건너뛰고** 멈춘 곳부터 이어서 합니다.
  - 해석 중이던 형상 1개만 처음부터 다시 합니다.
  - 다시 실행하면 창을 닫을 때 남은 Ansys 해석 프로세스를 먼저 자동으로 종료합니다.
- **중간 결과를 보내고 싶을 때**: `make_result_zip.bat`을 더블클릭하면 지금까지의 결과가 zip으로 묶입니다. 수집이 돌아가는 중에도 실행할 수 있습니다. 하루에 한 번 정도 올려 주시면 진행 상황을 확인할 수 있습니다.
- PC를 써야 할 때는 창을 닫고 쓰다가, 다 쓰면 다시 실행해 주세요.
- **창을 닫아도 Ansys 프로세스가 뒤에 남아 라이선스와 메모리를 계속 쓸 수 있습니다.** 그사이 Ansys를 직접 쓰거나 PC를 가볍게 쓰려면 재부팅하거나 작업 관리자에서 `AnsysWBU`를 종료해 주세요.
- 직접 연 Ansys 창이 있으면 수집을 시작하지 않고 안내 문구를 띄웁니다. 작업을 저장하고 닫은 뒤 다시 실행해 주세요.

## 선택 옵션

명령 프롬프트에서 키트 폴더로 이동한 뒤 옵션을 붙여 실행합니다.

```bat
run_collect.bat -Limit 1
```

- `-Limit N`: N개 형상만 돌리고 멈춥니다. 처음에 1개로 잘 도는지 확인할 때 씁니다.
- `-RetryFailed`: `error`, `timeout`으로 끝난 형상도 다시 돌립니다. `not_converged`는 같은 설정이면 결과가 같으므로 다시 돌리지 않습니다.
- `-MeshOnly`: 해석 없이 메시만 만들어 봅니다(점검용).

## 결과 파일 구성 (`results\<형상번호>\`)

| 파일 | 내용 |
|---|---|
| `partial_curve.csv`, `full_curve.csv` | 저장된 substep마다 변위, 반력, 변형 에너지(전체·바디별), **최대 von Mises 응력**(전체·바디별)과 그 위치 |
| `*_landmark_disp.csv` | 형상 꼭짓점과 측정점(55개)의 변위. 나중에 각도와 변형 형상을 계산할 때 씁니다 |
| `*_landmark_nodes.csv` | 각 꼭짓점에 쓴 노드 번호와 좌표 |
| `*_status.txt` | 해석 결과 상태(ok / not_converged / license_error / start_error / error / timeout), 메시 노드 수, 사용한 설정, 수렴한 마지막 시점(`completed_time`, 1.0이면 15 mm까지 완료) |
| `*_autofailed_*` | 첫 해석이 수렴하지 못한 경우에만 생깁니다. 실패하기 전까지의 곡선입니다 |
| `*_solve.out`, `*_post.out`, `wb_log.txt` | Ansys 로그 원본(문제 확인용) |
| `progress.csv` | 이 PC에서 끝난 해석 목록. 다시 돌린 형상은 행이 추가되며 가장 아래 행이 최신입니다 |

## 문제가 생기면

- 창에 노란 글씨로 `error`나 `timeout`이 찍혀도 다음 형상으로 넘어갑니다. 실패도 데이터이니 지우지 말고 그대로 보내 주세요.
- `license_error`나 `start_error`가 찍히면 형상 문제가 아니라 해석이 시작되지 못한 것입니다. 다시 실행하면 **이 형상들을 자동으로 다시 돌립니다.**
- 이런 오류가 **3개 형상 연속으로** 나면 수집이 스스로 멈춥니다. PC를 재부팅하고 다른 프로그램을 닫은 뒤 `run_collect.bat`을 다시 실행해 주세요.
- 계속 같은 오류가 나거나 창이 바로 닫히면, `results\progress.csv`와 해당 형상 폴더의 `wb_log.txt`를 보내 주세요.
