# 구축 검증 기록

2026-11-26 기준. 아래 구축 검증은 축소 실행 확인 기록이며, 실제 TPE 튜닝 검증은 문서 하단에 따로 기록합니다. 새 Test 평가는 아직 실행하지 않았습니다.

- 6개 후보 모두 공통 Train에서만 선택한 48개 형상으로 축소 학습, 6개 Train 형상 예측, 저장 후 재로딩 예측 일치 확인 완료.
- 실행 확인용 설정: MLP 너비 16·1층·4 epochs, XGBoost 8개 트리·깊이 2, GP 커널 최적화 생략, ROM 보정 최대 함수 평가 4회. 잠정 기본 설정의 성능이나 수렴을 의미하지 않습니다.
- MLP 분류/회귀 각각 네트워크 1개. 직접 출력 head와 예측 결과가 일치함을 확인했습니다. 모든 후보에서 별도 학습 모델의 예측 평균 없음.
- ROM 보정이 해당 Train 형상의 힘 곡선만 읽고, 다른 형상의 무효 곡선을 사용하지 않는지 확인했습니다. Train 부분집합이 바뀌면 ROM 캐시 fingerprint도 달라집니다.
- 원래 치수의 정규화가 ROM 추가 전후에 유지되는지 확인했습니다.
- Test 행을 fit에 전달하면 거부하고, 잘못된 하이퍼파라미터 이름을 거부하는지 확인했습니다.
- 기존 통합 테스트 9개와 신규 테스트 4개, 총 13개 통과. 새 후보별 직렬화 확인 6개 별도 통과.
- 원래 Forward 선택 파일·기존 가중치·평가 결과·역설계 어댑터를 바꾸지 않았습니다. 신규 테스트 파일·코드는 로컬 구축 상태이며 이번 요청으로 GitHub 게시하지 않았습니다.

로컬 실행 검증 산출물은 결과 루트의 `forward-six/smoke/validation.json`과 `forward-six/smoke/<candidate>/seed0.joblib`입니다. 체크용 가중치를 최종 학습 가중치로 사용하지 마세요.

이 Intel Mac의 XGBoost 검증에는 conda-forge 공식 OpenMP 21.1.8 런타임을 SHA-256 검증 후 사용했습니다. 로컬 결과 루트 `forward-six/runtime/`에 실행 라이브러리와 출처 기록을 보존합니다. 모델 코드에는 컴퓨터별 경로를 고정하지 않습니다.

## 20회 TPE 튜닝 검증

- 사용자 최종 선택에 따라 임시 15회 한도를 해제하고, 여섯 후보 모두 분류·회귀 각각 20개 COMPLETE trial을 완료했습니다. 총 240개 trial, 공통 5-fold 1,200개 평가 기록입니다. 첫 10회는 기본 설정 1개와 무작위 9개, 이후 10회는 TPE 제안입니다.
- 코드·데이터 SHA-256 일치, 모든 study 데이터베이스와 결과 파일의 완료 trial 일치, RUNNING trial 0개, 1,200개 검증 예측의 형상 ID·정답·fold 일치, 원본 예측에서 목적함수 재계산 일치를 확인했습니다. Test는 점수 계산에 사용하지 않았습니다.
- 각 ROM 보정은 해당 fold의 학습 형상 1,196개만 사용하며 held-out 형상 겹침 0개를 확인했습니다. 기본 모델/ROM 쌍의 초기 10개 설정 일치도 확인했습니다.
- 실행 환경 오류로 실패한 XGBoost 기본 설정 2개는 같은 설정을 재시도해 완료했으며 실패 이력은 보존했습니다.
- 실제 튜닝 및 재개 동작을 포함한 테스트 15개가 통과했습니다. 비교표·전체 탐색 이력·선택 설정·감사 기록·개선 추이 PNG를 결과 폴더에 저장하고 그림을 확인했습니다.
- GP 내부 최적화 1,000회 중 192회에서 성공 수렴이 보고되지 않았으며, 선택된 GP 설정의 내부 최적화 50회 중 15회도 이에 해당합니다. 최대 60회 상한과 세부 메시지는 fold 진단에 보존했습니다. 선택된 MLP 설정의 fold 학습 20개 중 6개는 최대 1,200 epochs를 선택했습니다. 따라서 모델 내부 최적화나 하이퍼파라미터 탐색이 모두 수렴했다고 주장하지 않습니다.
- 마지막 5개 trial에서 MLP 분류 F1이 0.005089, ROM+XGBoost 분류 F1이 0.003293 개선됐고, XGBoost 회귀 종합 오차는 약 2.46% 감소했습니다. 나머지 작업의 최고 점수는 이 구간에서 그대로였습니다. 정체는 해당 범위·예산·seed에서의 관찰이며 전역 최적의 증거가 아닙니다.
- 전체 Train 최종 재학습·새 Test 평가·역설계 Forward 교체·GitHub push는 이번 튜닝 작업에서 실행하지 않았습니다.
