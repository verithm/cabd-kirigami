## 기존 GP 탐색의 특징

외부 TPE는 Matérn ν 1.5/2.5와 길이 척도·신호 크기 초기값을 비교했다. 연속 커널 값은 내부 marginal-likelihood 최적화에서 다시 학습되므로 외부 초기값 변경이 같은 예측 결과로 이어질 수 있다. GP의 50회 중 동일한 전체 OOF hard-label 패턴이 최대 33회, ROM+GP는 최대 27회 반복됐다. 각 250 fold 모두 signal 상한 경고가 있어 내부 경계 진단이 필요하다. 경계 경고가 있다고 F1 개선이 보장되는 것은 아니다.

## 파일럿: 후보당 4개 설정 × 동일 5-fold

각 후보의 기존 50회 최적 설정을 기준으로 아래 변경을 적용한다. 기준 예측은 기존 저장 파일에서 읽어 새로 학습하지 않는다.

1. `bounds_only`: signal 상한 1e3→1e6, length 상한 1e3→1e5. 내부 최대 60회 유지.
2. `bounds_iterations`: 위 경계 확대 + 내부 최대 150회.
3. `rbf`: 확대 경계/150회 + RBF ARD 커널.
4. `matern05`: 확대 경계/150회 + Matérn ν=0.5 ARD 커널.

모든 파일럿은 기존 최적 설정의 signal/length 초기값을 유지한다. 각 단계 GP는 optimizer 재시작 0회, Laplace max_iter_predict 60회로 유지한다. 진단 중 Test는 예측하지 않는다. ROM 보정은 각 fold의 Train만으로 만든 기존 계수를 검증 후 재사용한다.

파일럿 전에 고정한 새 50회 실행 기준: 기존 최적 pooled OOF F1보다 **0.002 이상 높고 3개 이상 fold에서 개선**, 또는 **전체 F1이 0.005 이상 개선**. 이는 실무적 실행 판단 기준이며 통계적 유의성 검정이 아니다. 두 후보를 개별 판정한다. 조건을 만족한 후보만 새 50회를 진행한다.

## 새 탐색: 조건 만족 시 해당 GP 후보만 50 COMPLETE trial

- TPE seed 42, startup 10회, pruning 없음, 같은 고정 5-fold.
- 첫 설정은 파일럿의 조건 충족 최고 설정에서 시작한다. 이 설정도 내부 최대 150회로 다시 평가하며, 별도 trial로 센다.
- 커널: Matérn ν=0.5/1.5/2.5 또는 RBF.
- ARD(입력별 길이 척도) 또는 공통 길이 척도.
- signal 내부 상한: 1e3/1e4/1e6.
- length 내부 상한: 1e3/1e5.
- signal 초기값 log[0.01,1000], length 초기값 log[0.05,50].
- 내부 최대 150회, 재시작 0회, Laplace 최대 60회.

각 trial 5개 fold를 마친 후에만 다음 TPE 설정을 제안한다. SQLite, sampler, trial 설정, fold 예측/확률/최종 커널/최적화 경고/학습 시간/정답 검증을 저장한다. 중단 후 같은 소스·프로토콜로 재개한다.

## 비교 해석

새 GP가 좋아지면 기존 다른 후보와 함께 성능을 보고할 수 있지만, 새 GP는 기존 50회 외에 탐색 공간 설계 및 파일럿 기회를 더 받은 것이다. 따라서 과거와 완전히 같은 총 튜닝 기회를 받았다고 주장하지 않는다. 기존 공통 50회 표는 보존하고 새 결과에 이력을 표시한다. Test는 이미 프로젝트에서 확인한 고정 분할이며 이 실험의 설정 선택에 사용하지 않는다. 새로운 Test 평가나 배포 모델 교체는 이 스크립트에 포함하지 않는다.
