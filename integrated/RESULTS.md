# 공통 실험 결과와 해석

기준: 2026-11-22. **역설계 단일 최종 모델은 미확정**이며 아래 결과로 자동 선택하지 않습니다. 새 통합 후보의 ANSYS 해석은 실행하지 않았습니다. 원본 실험 파일은 로컬 결과 디렉터리에 보관합니다.

## Forward 선정

Train 내부 공통 5-fold에서 설정을 선택했습니다. 분류 F1, 회귀 MAE 기준으로 승민 MLP가 선정됐습니다. 분류 CV 차이는 작습니다(승민 MLP 0.954545, 진우 MLP 0.954315). 회귀 CV MAE는 승민 MLP가 각도 1.2830°, 변위 0.16674 mm, 로그 장벽 0.04125였습니다.

Test 결과는 설정 선택과 구분하며 학습 시드 0–4의 평균입니다.

| 출력 | Test 수 | MAE | RMSE | R² |
|---|---:|---:|---:|---:|
| 안정각 | 143 | 1.33285° | 1.66690° | 0.93659 |
| 변위 | 143 | 0.17548 mm | 0.22538 mm | 0.96961 |
| log10 장벽 | 143 | 0.04885 | 0.16031 | 0.92729 |

분류 Test 105개: F1 97.07%, Precision 99.57%, Recall 94.69%, Balanced Accuracy 97.17%. 이 점수에 역설계의 확률 0.9 필터를 적용한 것은 아닙니다.

Test 로그 장벽 MAE는 진우 MLP가 0.04260으로 더 작았습니다. 다만 Test를 보고 사후 교체하지 않고 CV 선정 원칙을 유지했습니다. 원래 mJ 단위에서는 승민 MLP의 오차가 더 작았습니다.

## 최초 역설계 비교

실제 Test 응답 49개×역설계 시드 3개, 방법별 147회. 각도 ±1.7°, 변위 ±0.23 mm, log10 장벽 ±0.16, 전환 확률 ≥0.9, 공식 형상 제약을 모두 적용했습니다.

| 방법 | 목표 발견률 | 개별 생성 후보 통과율 |
|---|---:|---:|
| Forward + SLSQP | 144/147 (98.0%) | — |
| Forward + DE | 141/147 (95.9%) | — |
| 조건부 GMM | 140/147 (95.2%) | 17.4% |
| 진우 CVAE | 136/147 (92.5%) | 49.7% |
| 승민 CVAE | 136/147 (92.5%) | 37.4% |

147개가 서로 다른 목표인 것은 아닙니다. 목표 발견률은 통과 후보를 하나 이상 찾은 비율이며, 생성 후보 통과율은 필터 전 원시 후보가 분모입니다. 같은 Forward로 선별·채점한 값이므로 독립적인 실제 성능 검증이 아닙니다.

## 목표 범위와 장벽 판정 변화

아래는 시드 0 하나입니다. 실제 Test49, 나머지 각 100개로 총 449개 목표×5방법=2,245회입니다. 각도 ±2°, 변위 ±0.25 mm, 원래 장벽 ±0.03 mJ를 적용해 생성·탐색한 뒤, 같은 후보에서 장벽 판정만 제외해 재평가했습니다.

| 목표 유형 | 진우 CVAE | 승민 CVAE | GMM | Forward+DE | Forward+SLSQP |
|---|---:|---:|---:|---:|---:|
| 실제 Test | 91.8→98.0% | 87.8→98.0% | 98.0→98.0% | 100→100% | 100→100% |

화살표는 장벽 포함→판정 제외입니다. **입력 장벽을 제거한 CVAE 재학습이 아니며, 최적화도 새 두 조건 목적함수로 재탐색한 것이 아닙니다.** 실제 Test에서 진우 CVAE 개별 후보 통과율은 13.2→59.1%, 승민은 6.4→48.1%, GMM은 5.2→29.2%였습니다.

로그 허용오차와 mJ 절대오차는 다릅니다. 목표 0.5 mJ에서 log10 ±0.16은 약 0.346–0.723 mJ, ±0.03 mJ는 0.47–0.53 mJ를 허용합니다. 큰 장벽에 더 엄격한 기준으로 바뀌었기 때문에 개별 통과율을 그대로 비교하면 안 됩니다.

## 현재 결론

- Forward: 승민 MLP 분류·공동 회귀 앙상블 선정.
- 역설계: 최종 단일 모델 미확정. 진우 CVAE는 개별 후보 통과율, GMM은 목표 대응 범위에서 강점이 있었습니다. SLSQP는 여러 유형에서 안정적이었지만 모든 조건에서 단일 우승이라고 선언하지 않습니다.
- 희소·경계에서 SLSQP가 찾은 목표를 생성 모델이 놓친 사례가 있으므로 실패를 모두 물리적 불가능성으로 설명할 수 없습니다.
- 독립 조합의 모든 방법 실패도 물리적 불가능성의 증명이 아닙니다.
- 실제 제작·해석 검증은 별도 단계입니다. 기존 각 버전의 과거 ANSYS 검증 성적을 이 통합 모델의 결과로 합치지 않습니다.
